wiring guide

Identity & season line

MLB Stats API — /api/v1/stats?stats=season&group=pitching for the roster and counting stats, /api/v1/people/{id} for bio. Tonight's starters: /api/v1/schedule?hydrate=probablePitcher.

Arsenal & shape

Baseball Savant statcast_search/csv. IVB/HB are pfx_z/pfx_x ×12, HB sign-flipped to arm-side. VAA is computed from vy0/vz0/ay/az — Savant has no VAA column.

Usage by count state

The same pitch table grouped by balls/strikes and stand. Ahead = more strikes than balls; two-strike counts are pulled out separately.

Running game

StatsAPI season pitching stats carry stolenBases, caughtStealing, pickoffs and wildPitches against. Time-to-plate is not published anywhere — you have to chart it off broadcast.

Location maps

plate_x/plate_z from the catcher's view, smoothed with a Gaussian kernel. Grouping follows Statcast's own pitch_type codes.

Whiff+ / Damage+

Local rate over a location-matched baseline built from every pitch in this build. Barrels use the standard launch_speed/launch_angle definition.
